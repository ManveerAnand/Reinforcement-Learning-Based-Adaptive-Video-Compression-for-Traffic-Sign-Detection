# IEEE Transactions Conversion Checklist

## Objective
Convert the current manuscript into IEEE Transactions style while preserving scientific content and claim boundaries.

## Source Inputs
- main_ieee.tex (copied from LNCS manuscript)
- refs_ieee.bib (copied bibliography)

## Conversion Steps
1. Replace document class and package setup with IEEE Transactions-compatible preamble.
2. Reformat title block, author block, and affiliations for IEEE style.
3. Add IEEE abstract and index terms formatting.
4. Reconcile section heading hierarchy to IEEE conventions.
5. Convert figures/tables/captions to IEEE sizing and placement style.
6. Convert equations, theorem-like blocks, and cross-references to IEEE style.
7. Convert citation style and bibliography backend to IEEEtran-compatible output.
8. Normalize acronym usage and symbol definitions for IEEE readability.
9. Ensure all claim-boundary language remains intact and explicit.
10. Run compile checks and fix all format-induced errors/warnings.

## Output Targets
- main_ieee.tex compiles with IEEE Transactions template style.
- refs_ieee.bib is compatible with IEEE bibliography processing.
- No unresolved references/citations in final PDF.
